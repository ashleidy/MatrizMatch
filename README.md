# MatrizMatch

**MatrizMatch** is a desktop application designed to analyze and process chemical compatibility matrices for the safe storage of hazardous substances. The system helps organize chemical information, verify compatibility relationships, and generate structured Excel matrices for industrial and educational environments.

The application was developed using **Python** and **PyQt5**, focusing on fast in-memory data processing instead of traditional database storage. This design allows the software to efficiently manipulate compatibility matrices without requiring persistent databases such as SQLite or MySQL.

## Main Features

* Chemical compatibility verification
* Substance categorization and grouping
* Excel matrix organization and formatting
* Compatibility and incompatibility analysis
* License validation and encrypted configuration system
* Desktop graphical interface built with PyQt5
* Automated Excel generation using OpenPyXL and Pandas

## Technologies Used

* Python
* PyQt5
* Pandas
* OpenPyXL
* Cryptography (Fernet encryption)

## Architecture

MatrizMatch follows a modular desktop architecture where each functionality is separated into independent windows and processing modules. The system processes compatibility data directly in memory to improve speed and reduce unnecessary storage dependencies.

## Purpose of the Project

This project was created to improve the organization and verification of chemical substance storage compatibility. The objective is to reduce manual analysis errors and simplify matrix generation processes for laboratories, educational institutions, and industrial environments.

Unlike traditional chemical inventory or compliance platforms, MatrizMatch was specifically designed to automate compatibility matrix analysis and substance storage validation workflows.

The system focuses on solving operational and engineering problems related to chemical compatibility classification, incompatibility verification, and automated matrix processing rather than inventory or regulatory management.

## Additional Notes

MatrizMatch is an independent software project and currently does not exist as a commercial or publicly distributed platform. The application was designed and developed as a custom technical solution focused on chemical compatibility management and Excel-based processing systems.

The software uses a lightweight desktop architecture with in-memory processing to provide fast analysis without relying on persistent databases or cloud infrastructure.
